# Оповещения DonationAlerts + Donatty для PRISM

Одна Web-ссылка подключает оба сервиса. Страница прозрачная, пока нет оповещения.
Существующий рейтинг и сборы в `index.html` работают отдельно.

## Подключение

1. Открой `https://pomsergey.github.io/Top/alerts.html`.
2. Вставь полные ссылки на свои виджеты DonationAlerts и Donatty, нажми «Создать общую ссылку».
3. Скопируй результат целиком, включая часть после `#`, в один Web-источник PRISM.
4. Подбери размер и положение источника в сцене. Проверь картинку и звук тестовыми оповещениями в обоих сервисах.
5. Удали или отключи прежние отдельные источники, чтобы не получать двойной звук.

Готовая персональная ссылка также сохранена локально в `outputs/PRISM-alerts-link.txt`
в рабочей папке этой задачи. В публичном репозитории ключей нет.
Сама персональная ссылка содержит ключи и предназначена только для владельца.

## Как работает

Donatty загружается своим оригинальным виджетом в iframe, с его собственным оформлением и звуком.
DonationAlerts запрещает iframe с другого сайта (`frame-ancestors 'self'`). Поэтому для него
используется прямое подключение к серверу событий тем же ключом виджета, а также JSONP
для получения настроек и ожидающих оповещений. Сервер-посредник не используется.

Для DonationAlerts реализованы донаты (тип 1), очередь внутри сервиса, подавление повторов
по ID, автоматическое переподключение, проверка ожидающих оповещений каждые 10 секунд,
картинки, звуки, заголовки и основные стили текста из группы виджета. Учитываются
условия по сумме и принудительный выбор варианта для тестового оповещения.
Служебные значения `is_shown` в аккаунте не изменяются.

Это собственный проигрыватель DonationAlerts: точная анимация его оригинального виджета
и другие типы событий (например, подписки) здесь не воспроизводятся.
Его внутренний интерфейс виджета может измениться независимо от этой страницы.

## Звук и озвучка

Звуки и картинки DonationAlerts берутся из текущих настроек сервиса. Для готового
`tts_url`, если он пришёл в событии, проигрывается файл сервиса. Иначе озвучка DonationAlerts
использует голос устройства при наличии SpeechSynthesis и при достижении настроенного порога.
Оригинальный API генерации голоса DonationAlerts не разрешает запросы с другого сайта.
Поэтому этот вариант не гарантирует прежний голос или вообще поддержку озвучки в PRISM
на конкретном телефоне. Звук и речь нужно проверить на устройстве перед стримом.
Озвучкой Donatty продолжает управлять сам Donatty.

Оба сервиса используют одно место на экране. При одновременных событиях из разных сервисов
оповещения и звук могут пересечься; общая очередь между двумя сервисами не реализована.

## Проверка

- `alerts.html?preview=1` показывает безопасную демонстрацию без подключения к сервисам.
- `?status=1` перед `#` добавляет диагностику; у рабочей ссылки этого параметра нет.
- «Страница Donatty загружена» подтверждает загрузку страницы, а не доставку настоящего доната.
- «Соединение DonationAlerts установлено» подтверждает транспорт; окончательная проверка — тест из личного кабинета.

Если в PRISM страница пустая в ожидании доната — это нормально. Если видна форма настройки,
персональная ссылка вставлена не целиком.
